# CLI UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make Codejitsu's CLI usage and help output feel like Symfony Console, with grouped subcommands, descriptions, colors, and useful suggestions.

**Architecture:** Keep command discovery and execution in the existing `Codejitsu\Apps\Cli` and `Command` layers. Add a small renderer dedicated to terminal presentation so command resolution/execution remains separate from formatting. Reuse Symfony Console's `OutputFormatter` instead of inventing ANSI handling.

**Tech Stack:** PHP 8.4+, Symfony Console 8.x, PHPUnit 13.

**Spec:** CLI UX design approved in chat on 2026-08-25.

## Global Constraints

- Preserve the existing Scroll-driven command model.
- Use Symfony Console formatting primitives; do not hand-roll ANSI escape codes.
- Keep command execution behavior unchanged.
- Main help must show namespace children without requiring separate namespace invocation.
- Tests must verify semantic output and avoid brittle raw ANSI assertions.
- Maintain `declare(strict_types=1);`.
