# Codejitsu Data Roadmap

## Next

- Execute ordered `strategy://` pipelines by phase without making Strategy a Data-owned type.
- Compile repository metadata and specialized repository classes through Buildshido.
- Enforce Repository Scroll allowlists for dynamic filters, ordering, pagination, and named queries.
- Execute entity lifecycle hooks with transaction-aware `afterCommit` and outbox support.
- Add relations, composite identifiers, optimistic locking, migrations, and richer SQL operators.
- Add a native MongoDB Store adapter without forcing document behavior through SQL abstractions.
- Add legacy source readers, field maps, authority/confidence metadata, lineage, and progressive migration state.
- Add projections for vector, time-series, blob, search, and other specialized stores as Kuzuryu foundations.
- Let UI/API Resource Scrolls consume compiled repository capabilities for generated CRUD and endpoints.
